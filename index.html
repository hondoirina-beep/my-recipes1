База продуктов

КБЖУ указываются на 100 г. Встроенные значения можно редактировать; новые продукты сохраняются локально.

Резервная копия

Экспортирует рецепты, продукты, норму КБЖУ и сохранённые меню в один JSON-файл.

Локальные данные

Данные дублируются в localStorage и IndexedDB этого браузера. Если файл открыт напрямую как file://, браузер всё равно может не сохранить их между запусками.

Добавить рецепт

Вставьте рецепт текстом — затем проверьте карточку.

КБЖУ на фиксированную порцию рецепта

Можно ввести вручную или рассчитать по базе продуктов, если для всех ингредиентов указан вес в граммах (или кг) и они найдены в базе.

Добавить рецепты списком

Вставьте сразу несколько рецептов. Перед сохранением приложение покажет, как оно их распознало.

Самый надёжный способ: между рецептами поставьте отдельную строку ---. Если разделителей нет, приложение попробует найти границы автоматически по повторяющимся блокам «Ингредиенты».
